## 学習のクセ・注意点

- 暗算しようとして桁を間違えることがある → **重みを必ず書き出す**よう促す
- 直前に解いた問題のルールを引きずる（AND の直後に OR を AND として解いた）
- 答えを書くとき桁数をそろえない（`110` → `0110` と書く癖をつける）
- **反例チェック**（具体値を入れて式が壊れるか試す）を教えた。使えるようになると強い
